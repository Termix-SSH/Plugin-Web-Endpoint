<h1>Web Endpoint</h1>

<p>Open a host's web UI inside Termix, directly or over an SSH tunnel</p>

</div>

<br />

## Overview

Web Endpoint opens a host's own web interface, like a router admin page, inside Termix instead of a separate browser tab.

<br />

## Features

- Open a web UI in a Termix tab or its own desktop window
- Connect directly, or over an SSH tunnel through the host
- Embedded pages never see your Termix login

## Support

Found a bug or have an idea for Web Endpoint? Open an issue in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Web-Endpoint/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Web-Endpoint/issues/new?template=feature_request.yml). The quickest way to report a bug is **Report an issue** on this plugin's page in the Termix Plugins tab, which fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Please be as detailed as possible, preferably in English. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
